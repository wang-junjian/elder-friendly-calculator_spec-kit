# Contract: UI 契约（界面验收项）

**Date**: 2026-10-07 | **Feature**: [spec.md](spec.md)

本契约定义界面的可验证验收项。评审与 UI 测试据此核对，全部条款来自 spec 功能需求
与章程原则 I/V，实现时由 `AccessibilityMetrics` 常量统一保证。

## 布局

| # | 条款 | 来源 |
|---|------|------|
| U1 | 单窗口、单屏：显示区在上，键盘网格在下；无菜单式隐藏功能入口 | FR-001 |
| U2 | 键盘网格：数字 0–9、小数点、加、减、乘、除、等于、退格、清除；清除/退格使用通俗中文标签 | FR-001/006 |
| U3 | 语音开关在界面可见位置（开关或菜单项），状态即时可见 | FR-012 |
| U4 | 窗口最小尺寸 480×640pt，小于此值不可调整；默认 560×760pt | FR-014 |
| U5 | 窗口放大时按钮与字号按比例增大；缩小时不小于最小值 | Edge Case |

## 适老度量（硬性验收线）

| # | 条款 | 来源 |
|---|------|------|
| U6 | 结果显示字号：默认窗口下 ≥48pt；任何允许窗口尺寸下 ≥24pt | FR-002 |
| U7 | 按钮点击目标 ≥64×64pt（底线 44×44pt），相邻间距 ≥12pt | FR-003 |
| U8 | 文本/背景对比度 ≥4.5:1（实现取 ≥7:1）；大面积元素 ≥3:1 | FR-004 |
| U9 | 按键按下有即时视觉反馈（按下态高亮/缩放），延迟 <100ms | FR-011 |

## 键盘映射（macOS 13 兼容方案，见 research R3）

| 物理按键 | 行为 |
|----------|------|
| 0–9、小数点 | 对应数字/小数点输入 |
| `+` `-` `*` `/` | 对应运算符 |
| Return / Enter | 等于 |
| Delete (Backspace) | 退格 |
| Escape | 清除 |

映射行为与鼠标点击完全一致（FR-005）。

## 无障碍

| # | 条款 | 来源 |
|---|------|------|
| U10 | 每个按钮有 `accessibilityLabel`（“数字 7”“加号”“等于”等）与 `accessibilityHint` | 原则 V |
| U11 | 结果变化向 VoiceOver 发送通告（announcement），读出新结果 | 原则 V |
| U12 | 尊重系统“增大对比度”“减弱动态效果”设置 | 原则 V |
| U13 | 全部功能仅键盘可完成；无双击/长按/拖拽等唯一路径手势 | FR-005、原则 V |

## 语音播报

| # | 条款 | 来源 |
|---|------|------|
| U14 | 默认关闭；开启后按键与结果用中文播报（“12 加 7 等于 19”）；开关状态重启后保持 | FR-012 |
| U15 | 新播报打断进行中的旧播报，不叠加 | research R4 |

## 反馈文案

- 除零：`不能除以 0`
- 溢出：`数字太大了`
- 任何界面文本不出现英文术语、错误码或技术名词（章程原则 IV）
