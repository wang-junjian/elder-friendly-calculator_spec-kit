# Quickstart: 验证指南

**Date**: 2026-10-07 | **Feature**: [spec.md](spec.md)

本指南用于验证特性端到端可用。验证场景直接映射 spec 验收场景与成功标准。

## 前置条件

- macOS 13+，Xcode 15+（Swift 6 工具链）
- 无需网络、无需任何账号或第三方依赖安装

## 构建与测试

```bash
# 单元测试（引擎全分支 + 度量常量合规 + 播报文案）
xcodebuild test -project ElderCalculator/ElderCalculator.xcodeproj \
  -scheme ElderCalculator -destination 'platform=macOS'

# 运行应用
xcodebuild build -project ElderCalculator/ElderCalculator.xcodeproj -scheme ElderCalculator
open ~/Library/Developer/Xcode/DerivedData/*/Build/Products/Debug/ElderCalculator.app
```

## 端到端验证场景

### V1 — P1：基础四则运算（US1 验收场景 1–4）

1. 启动应用 → 显示区显示大字号 `0`，全部按钮单屏可见，无需滚动
2. 鼠标依次点击 `1` `2` `＋` `7` `＝` → 显示 `19`
3. 键盘输入 `3` `*` `4` 回车 → 显示 `12`（与点击行为一致）
4. 结果显示后直接按 `5` → 显示 `5`，开始新计算

**预期**：结果始终为整齐整数/有限小数；字号在默认窗口下明显大于系统常规文本。

### V2 — P2：防错与纠正（US2 验收场景 1–4）

1. 输入 `123` 后按退格两次 → 显示 `1`
2. 输入 `8` `÷` `0` `＝` → 显示“不能除以 0”，应用无卡死；随后按 `9` → 正常开始新输入
3. 按 `5` `＋` `×` `3` `＝` → 显示 `15`（后以的运算符生效）
4. 任意状态按“清除”（或 Escape）→ 显示 `0`

### V3 — P3：语音播报（US3 验收场景 1–3）

1. 默认状态：操作不发声
2. 开启语音开关 → 输入 `3` `×` `4` `＝` → 听到中文播报“3 乘 4 等于 12”
3. 退出应用重新启动 → 开关保持开启；关闭后重启 → 保持关闭
4. 无论语音开关状态，每个按钮按下均有即时按下态视觉变化

### V4 — 边界与度量（Edge Cases + SC）

1. 连续输入 13 位以上数字 → 第 13 位起被忽略，显示不溢出
2. `1` `÷` `3` `＝` → 显示 `0.33333333`
3. `999999999999` `×` `999999999999` `＝` → 显示“数字太大了”
4. 拖拽窗口缩小 → 最小停在 480×640，按钮与字号不低于适老底线
5. 秒表测量：双击图标到可输入 ≤2 秒；按键到视觉反馈无可见延迟
6. 开启 VoiceOver（⌘F5）→ 每个按钮可朗读标签，结果变化有通告
