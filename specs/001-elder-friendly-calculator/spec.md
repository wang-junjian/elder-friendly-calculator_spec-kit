# Feature Specification: 适老友好计算器（macOS 原生应用）

**Feature Branch**: `001-elder-friendly-calculator`

**Created**: 2026-10-07

**Status**: Draft

**Input**: User description: "给老人开发一款计算器 macOS 原生应用。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 大字号界面完成基础四则运算 (Priority: P1)

一位 65 岁以上、视力有所下降的用户打开应用，看到一个单窗口界面：数字与运算符按钮
大而稀疏、显示区字号醒目。用户用鼠标点击（或键盘敲击）依次输入数字与运算符，
按下等号后立即看到清晰放大的计算结果。

**Why this priority**: 这是产品的核心价值——让老年用户能够独立、不费力地完成日常计算
（算账、算药量、分摊费用等）。没有这一条，产品不成立；仅此一条即可构成可用的 MVP。

**Independent Test**: 可通过“启动应用 → 输入 12 + 7 = → 确认显示 19”完整验证，
独立交付“老年用户可完成一次加法计算”的价值。

**Acceptance Scenarios**:

1. **Given** 应用已启动且显示为初始状态（显示 0），**When** 用户依次点击数字 1、2、
   加号、7、等号，**Then** 结果显示区以默认大字号清晰显示 19
2. **Given** 应用窗口处于默认大小，**When** 用户不调整任何设置直接操作，**Then** 所有
   按钮与结果显示在默认窗口内完整可见，无需滚动或翻页
3. **Given** 用户正在进行输入，**When** 用户使用键盘数字键与 +、-、*、/、回车键操作，
   **Then** 计算行为与鼠标点击完全一致
4. **Given** 一次计算已得出结果，**When** 用户直接输入新数字，**Then** 上一结果自动清空，
   开始一次全新计算

---

### User Story 2 - 误操作纠正与防错保护 (Priority: P2)

老年用户手指抖动或看错按钮，输错了数字或运算符。用户可以通过明显的“退格”键逐位
删除，或用“清除”键一键重来；输入非法操作（如除以零、连按两次运算符）时，应用不会
崩溃或显示莫名其妙的错误，而是用通俗的话提示并保持在可继续操作的状态。

**Why this priority**: 误操作在老年用户中高频发生。若无法轻松纠正或出错后界面“卡住”，
用户会立即失去对产品的信任。这是仅次于核心计算的可用性支柱，但 P1 的 MVP 可暂不含
完善的防错细节。

**Independent Test**: 可通过“输入 8 ÷ 0 = → 确认显示通俗提示且不崩溃 → 按清除 →
重新计算成功”独立验证。

**Acceptance Scenarios**:

1. **Given** 用户已输入若干数字，**When** 用户点击“退格”，**Then** 当前输入的最后一位
   被删除，显示即时更新
2. **Given** 用户输入了 8 ÷ 0 并按等号，**When** 计算被尝试执行，**Then** 显示区给出
   通俗提示（如“不能除以 0”），应用保持响应，用户可直接开始新输入
3. **Given** 用户刚按过一个运算符，**When** 用户再次按下另一个运算符，**Then** 以最新
   按下的运算符为准（替换而非报错或连算）
4. **Given** 任意输入状态，**When** 用户点击“清除”，**Then** 全部输入与结果重置为
   初始状态（显示 0）

---

### User Story 3 - 操作反馈与语音播报 (Priority: P3)

用户每次按键都有明确的视觉反馈（按钮按下态变化）；视力较弱的用户还可以开启语音播报，
应用用中文读出按下的数字、运算符和最终结果（如“12 加 7 等于 19”），帮助用户核对
输入是否正确。

**Why this priority**: 语音播报对低视力用户价值很大，但对多数用户而言视觉反馈已够用；
属于增强项，放在核心计算与防错之后交付。

**Independent Test**: 可通过“开启语音开关 → 输入 3 × 4 = → 听到‘3 乘 4 等于 12’的
中文播报”独立验证。

**Acceptance Scenarios**:

1. **Given** 语音播报处于开启状态，**When** 用户完成一次完整计算，**Then** 应用用中文
   依次播报输入过程与结果
2. **Given** 语音播报处于开启状态，**When** 用户点击界面上的语音开关（或菜单项）关闭它，
   **Then** 后续操作不再发声，且该偏好在下次启动时保持
3. **Given** 任意时刻，**When** 用户按下任意按钮，**Then** 按钮有立即可见的按下态
   视觉变化（无论语音是否开启）

---

### Edge Cases

- 输入超长数字（超过显示宽度）时如何呈现？——限制最大输入位数（如 12 位），到达上限后
  忽略后续数字输入并给出轻微提示。
- 计算结果超出可精确表示范围（如极大数）时如何呈现？——以老年用户可读的方式显示
  （合理位数内完整显示，超出时用简洁科学计数或提示“数字太大了”），禁止显示乱码或
  技术性错误码。
- 小数计算产生无限循环小数（如 1 ÷ 3）时如何呈现？——四舍五入到合理小数位数
  （如 8 位）显示，结果重新参与计算时使用显示值。
- 应用在用户切换到其他程序再切回后，当前输入状态是否保留？——保留，不得因窗口
  失焦而清空。
- 用户调整窗口大小时界面如何响应？——按钮与字号随窗口适度缩放，但不允许缩到低于
  适老最小尺寸（窗口有最小尺寸约束）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 应用 MUST 提供 0–9 数字键、小数点键，以及加、减、乘、除四个运算符键，
  全部以单窗口、单屏布局呈现，无隐藏菜单式入口。
- **FR-002**: 结果显示区默认字号 MUST 不小于 24pt 等效可视尺寸，且在所有支持的窗口
  尺寸下保持清晰可读。
- **FR-003**: 所有可点击按钮的点击目标 MUST 不小于 44×44 点，按钮间距 MUST 足以
  防止相邻误触。
- **FR-004**: 界面文字与背景的对比度 MUST 不低于 4.5:1，按钮等大面积元素不低于 3:1。
- **FR-005**: 应用 MUST 支持完整的键盘操作：数字键、小数点、+、-、*、/、回车（等于）、
  Delete/Backspace（退格）、Escape（清除），行为与鼠标点击一致。
- **FR-006**: 应用 MUST 提供“退格”（删除当前输入最后一位）与“清除”（重置全部状态）
  两个纠错操作，且按钮标签使用通俗中文（如“退格”“清除”）。
- **FR-007**: 遇到除以零时，应用 MUST 显示通俗中文提示（如“不能除以 0”），不得崩溃、
  卡死或显示技术性错误信息。
- **FR-008**: 连续按下运算符时，MUST 以最后按下的运算符为准，不得报错或立即连算。
- **FR-009**: 得出结果后直接输入数字，MUST 自动开始新计算（清空上一结果）。
- **FR-010**: 应用 MUST 限制单次输入的最大位数（12 位），超限输入被忽略。
- **FR-011**: 每次按键 MUST 有即时视觉反馈（按下态变化），反馈延迟低于 100 毫秒。
- **FR-012**: 应用 MUST 提供可开关的中文语音播报功能，播报按键输入与计算结果；开关状态
  MUST 在应用重启后保持。语音默认关闭。
- **FR-013**: 应用 MUST 在窗口失焦或最小化后恢复时保留当前计算状态。
- **FR-014**: 应用 MUST 设置窗口最小尺寸，确保任何情况下按钮与字号不低于适老最小标准。
- **FR-015**: 应用 MUST 完全离线运行，不收集、不上传任何用户数据，不要求账户或网络权限。

### Key Entities

- **计算会话（Calculation Session）**: 一次从输入到得出结果的完整过程，包含当前输入的
  数字、已确认的操作数、待执行的运算符与最终结果；随“清除”或新计算重置。
- **用户偏好（User Preferences）**: 语音播报开关状态；需跨启动持久保存，仅存于本机。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 65 岁以上首次接触该应用的用户中，90% 能在无人协助的情况下于 1 分钟内
  完成一次“两位数加法”任务。
- **SC-002**: 用户在默认窗口下无需调整任何设置，即可看清全部按钮与结果（可用性测试中
  100% 受试老年用户确认可读）。
- **SC-003**: 输错数字的用户中，95% 能借助退格/清除在 10 秒内纠正并继续计算。
- **SC-004**: 应用从点击图标到可进行首次输入不超过 2 秒；任意按键到视觉反馈不超过
  100 毫秒。
- **SC-005**: 100% 的非法操作（除零、连续运算符、超长输入）以通俗提示或被安全忽略，
  无崩溃、无技术性错误码。
- **SC-006**: 所有界面文本与按钮达到 4.5:1 对比度标准，通过可访问性检测工具核查。

## Assumptions

- 目标用户为 60 岁及以上、具备基本鼠标或键盘操作能力的中文用户；应用界面语言为中文。
- 功能范围严格限定为加减乘除四则运算（遵循章程“简洁至上”原则）；科学计算、历史记录、
  货币换算等功能明确不在本期范围内。
- “macOS 原生应用”指遵循 macOS 人机交互规范、以标准窗口形态运行的桌面应用；
  支持当前受 Apple 官方维护的 macOS 版本。
- 语音播报使用系统自带的中文语音能力，无需联网。
- 除“语音播报开关”外无其他需要持久化的设置；不引入账户、同步或网络功能。
